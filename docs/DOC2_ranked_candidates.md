# Ranked lipid candidates for the α-synuclein / ThT screen

**What this is.** 107 defined lipids scored by the rule-based prior (see `DOC1_lipid_decision_tree.md`) for **Yuval's regime** (A53T, pH 7.4, high lipid:protein, aggregation baseline). **Score ≥ 2 → likely reducer · 0–1 → inert/mild · < 0 → likely promoter.** Higher = more likely to *reduce* fibrils.

> ⚠ **Prior, not measurement.** Direction is pinned to Yuval's conditions; the 'anionic → reducer' branch holds at his *high* ratio + neutral pH (at low ratio the same lipids accelerate). Lipids are added **'free' from ethanol**, not as vesicles — assembly state TBD. Re-fit on Yuval's data after batch 1.

## Recommended for batch 1 (what's on the plate)

**Test the prior's main prediction — anionics reduce, the PC/cholesterol set doesn't:**

- **Strong-reducer bets (anionic):** GM1, **GM3**, **DOPS**, **POPG**, **cardiolipin** — top of the list, and the 4 non-GM1 ones were *added* to the plate for exactly this test.
- **Candidate reference set:** DMPC, DPPC, DSPC, DOPC, POPC, SM, cholesterol — spans mild-reduce → inert → predicted-promote, so they calibrate the whole axis.
- **Built-in negative/directional controls:** cholesterol & DPPC (predicted promoters) tell us if the assay + rule sign are right.

**Not on the plate but high-value next (if the anionic prediction holds):** other gangliosides (GD1a, GT1b), short-chain PS/PG (DMPS, DMPG), PA lipids.
